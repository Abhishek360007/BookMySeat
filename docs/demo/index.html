BookMySeat

Movie ticket booking that guarantees one booking per seat, even when many people try to book the same seat at the same moment. Every step below is captioned in the video.

Source code on GitHub Live app API docs

What the video shows

  1. 01
    Browse and search shows by title and city
  2. 02
    Live seat map: available, held and booked seats
  3. 03
    Create an account: BCrypt passwords, JWT sessions
  4. 04
    Pick seats: up to 10, with a running total
  5. 05
    Hold for 5 minutes: one atomic Redis Lua script
  6. 06
    Confirm the booking: optimistic locking, idempotent retries
  7. 07
    My bookings and cancellation
  8. 08
    Emails through a transactional outbox
  9. 09
    Documented REST API in Swagger UI
  10. 10
    Admin dashboard: sales, live seat map, show management
